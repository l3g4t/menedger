# Как получить и подключить модель помощника (пошагово)

Эта папка — не часть приложения (CLAUDE.md, раздел 9.4). Здесь готовится файл
`assistant_model.gguf` — «мозг» помощника. Без него чат отвечает по базе знаний (`assistant/faq.py`), и для защиты проекта этого достаточно (CLAUDE.md, раздел 9.5).

## Шаг 1. Обновить проект
```
git pull
pip install -r requirements.txt
```

## Шаг 2. Проверить обучающие примеры
```
python -m training.prepare_dataset
```
Откройте `training/data/review.md` и прочитайте ответы. Что поправить:
* неверные или спорные советы;
* слишком длинные ответы (должны быть 2–5 предложений);
* всё, что вы не смогли бы объяснить на защите.
Общие ответы правятся в базе знаний `assistant/faq.py`, шаблоны ответов по
состоянию хранилища — в `training/prepare_dataset.py`. После правок запустите
команду выше снова — `training/data/dataset.jsonl` пересоберётся.

## Шаг 3. Дообучить модель в Google Colab (бесплатно, ~10–20 минут)
1. Зайдите на https://colab.research.google.com и создайте новый блокнот.
2. «Среда выполнения» → «Сменить тип среды выполнения» → **T4 GPU**.
3. Слева откройте «Файлы» и загрузите `training/data/dataset.jsonl`.
4. Первая ячейка: `!pip install unsloth` — запустить.
5. Вторая ячейка: вставьте всё содержимое `training/finetune_colab.py` — запустить.
6. По окончании в «Файлах» появится папка `assistant_model_gguf` — скачайте из неё
   файл с расширением `.gguf` (около 400 МБ).
`finetune_colab.py` не проверялся на реальном GPU: если ячейка выдаст ошибку,
скопируйте её текст целиком — исправим.

**Без обучения (быстрый вариант):** вместо шагов 2–3 скачайте готовый
`qwen2.5-0.5b-instruct-q4_k_m.gguf` со страницы `Qwen/Qwen2.5-0.5B-Instruct-GGUF`
на huggingface.co. Заработает, но хуже держит формат ответов.

## Шаг 4. Положить модель на место
Переименуйте файл в **`assistant_model.gguf`** и положите в одно из мест
(проверяются по порядку): путь из переменной `MENEDGER_MODEL`; рядом с
`menedger.exe`; папка `~/.menedger/` (на Windows `C:\Users\<имя>\.menedger\`);
папка `models/` в проекте.

## Шаг 5. Поставить движок
```
pip install -r requirements-assistant.txt
```
Пакет `llama-cpp-python` на Windows ставится из готовых сборок (индекс указан в
файле). Если pip начал что-то компилировать и просит Visual Studio — готовой
сборки для вашей версии Python нет: напишите разработчику, вывод `pip` и
`python --version`.

## Шаг 6. Проверить, что модель работает
```
python -m assistant.selftest
```
Команда покажет, где найден файл, за сколько секунд загрузилась модель и ответы
на три тестовых вопроса. Эти ответы и время — главное, что нужно прислать.

## Шаг 7. Запустить приложение
```
python -m gui.app
```
Разблокируйте хранилище → «Помощник». В заголовке окна должно быть написано
«локальная модель», а не «работает на шаблонах».

## Шаг 8. Для `.exe`
Перед `packaging\build_windows.bat` выполните шаг 5 (иначе движок не попадёт в
`.exe`). Файл `assistant_model.gguf` в `.exe` не упаковывается — положите его
рядом с готовым `dist\menedger.exe`.
