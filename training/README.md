# Дообучение помощника (DEV-ONLY)

Эта папка — не часть приложения: пользователю она не нужна (CLAUDE.md,
раздел 9.4). Здесь готовится файл `assistant_model.gguf`.

1. **Проверьте данные.** `python -m training.prepare_dataset` собирает
   `data/dataset.jsonl` (около 110 примеров) и `data/review.md` — читаемую
   версию. Общие ответы правятся в `data/general_qa.json`, шаблоны ответов по
   состоянию хранилища — в `prepare_dataset.py`. После правок запустите
   скрипт заново.
2. **Обучите в Google Colab:** `finetune_colab.py` (инструкция в начале файла).
   Скрипт не проверялся — см. предупреждение в нём.
3. **Подключите модель:** скачайте `.gguf`, переименуйте в
   `assistant_model.gguf` и положите: рядом с `menedger.exe`, либо в
   `~/.menedger/`, либо в `models/` проекта, либо укажите путь в переменной
   `MENEDGER_MODEL`. Нужен также пакет из `requirements-assistant.txt`.

Без дообучения можно сразу подключить обычный `Qwen2.5-0.5B-Instruct` в
формате GGUF (Q4_K_M) — он тоже заработает, но хуже держит формат ответов.
