# menedger — локальный менеджер паролей

Локальный CLI-менеджер паролей с зашифрованным хранилищем на диске.
Все данные шифруются AES-256-GCM, ключ выводится из мастер-пароля через
Argon2id — подробное обоснование архитектурных решений (формат
хранилища, крипто-примитивы, атомарная запись) см. в
[`CLAUDE.md`](CLAUDE.md).

## Установка

Требуется Python 3.11+.

```bash
pip install -r requirements.txt
```

Графический интерфейс использует Tkinter — обычно уже входит в
стандартную поставку Python; если `python3 -c "import tkinter"` падает
с ошибкой, на Linux доустановите системный пакет (например,
`sudo apt install python3-tk` на Debian/Ubuntu).

## Графический интерфейс

```bash
python -m gui.app
```

Открывает окно: экран разблокировки/создания хранилища → список записей
с поиском → добавление/просмотр/смена пароля/удаление записи, советник
по безопасности и генератор паролей — те же возможности, что и в CLI,
под тем же самым файлом хранилища (`~/passwords.vault` по умолчанию,
можно выбрать другой файл кнопкой «Обзор...»). Архитектура и обоснование
выбора Tkinter — CLAUDE.md, раздел 10.

## Быстрый старт (CLI)

```bash
# Создать новое хранилище (запросит и попросит подтвердить мастер-пароль)
python -m vault.cli create

# Добавить запись
python -m vault.cli add github.com --username alice

# Показать сайты и логины (без паролей)
python -m vault.cli list

# Показать логин и пароль для сайта
python -m vault.cli get github.com

# Сменить пароль существующей записи
python -m vault.cli update github.com

# Удалить запись (спросит подтверждение)
python -m vault.cli delete github.com

# Проверить хранилище на слабые/повторные/устаревшие пароли
python -m vault.cli audit

# Сгенерировать криптостойкий пароль (не требует мастер-пароля)
python -m vault.cli generate --length 24
```

По умолчанию хранилище лежит в `~/passwords.vault`. Свой путь — флагом
`--path`, указанным ПЕРЕД именем команды:

```bash
python -m vault.cli --path ./work.vault create
python -m vault.cli --path ./work.vault add example.com
```

## Команды

| Команда | Что делает |
|---|---|
| `create [--force]` | Создать новое хранилище. `--force` — пересоздать существующее (старые данные будут потеряны). |
| `add <site> [--username U]` | Добавить запись. Пароль запрашивается интерактивно, без эха на экране. |
| `list` | Показать сайты и логины — без паролей. |
| `get <site>` | Показать логин/пароль/дату для сайта (все совпадения, если их несколько). |
| `update <site> [--username U]` | Сменить пароль записи. `--username` нужен, если на сайте несколько аккаунтов. |
| `delete <site> [--username U] [--yes]` | Удалить запись(и). Спрашивает подтверждение, если не передан `--yes`. |
| `audit` | Эвристический советник по безопасности: повторно используемые, слабые и устаревшие пароли. |
| `generate [--length N] [--no-symbols] [--no-digits] [--no-uppercase] [--no-lowercase]` | Сгенерировать криптостойкий пароль. Печатает пароль в stdout, объяснение — в stderr. |

## Сборка отдельного приложения (без установки Python)

Через [PyInstaller](https://pyinstaller.org/) собирается один
исполняемый файл — на целевой машине не нужен ни Python, ни
`pip install`, только сам файл.

**Windows — проще всего:** установите Python с [python.org](https://python.org)
(отметьте «Add python.exe to PATH» при установке), затем дважды
кликните по `packaging\build_windows.bat` — скрипт сам поставит
зависимости и соберёт файл, ничего вводить в терминал не нужно.

**Linux/macOS (или вручную на Windows):**

```bash
pip install -r requirements.txt -r requirements-build.txt
pyinstaller packaging/menedger.spec
```

Результат — `dist/menedger` (Linux/macOS) или `dist/menedger.exe`
(Windows), около 15–25 МБ, один файл. **Собирать нужно отдельно на
каждой целевой ОС** — PyInstaller не кросс-компилирует: файл, собранный
на Linux, не запустится на Windows, и наоборот. Подробности и
обоснование выбора PyInstaller — CLAUDE.md, раздел 11.

## Безопасность

- Пароли на диске всегда зашифрованы AES-256-GCM, ключ выводится из
  мастер-пароля через Argon2id.
- Мастер-пароль нигде не сохраняется — забытый мастер-пароль означает
  безвозвратную потерю доступа к хранилищу. Это осознанный компромисс:
  любой способ восстановления пароля ослабил бы всю схему шифрования.
- Секреты вводятся только через скрытый ввод (`getpass`) — никогда не
  передавайте пароли аргументами командной строки, они остаются в
  истории шелла и видны в выводе `ps aux`.
