# Список утёкших паролей

`common_passwords.txt.gz` — первые 1 000 000 строк rockyou.txt (самые частые
пароли из взлома RockYou, 2009), в нижнем регистре, без повторов: 962 483 пароля.
Только пароли, без логинов и адресов. Используется проверкой слабых паролей
(`assistant/wordlist.py`, CLAUDE.md раздел 9.6). Пересборка — `python
packaging/build_wordlist.py rockyou.txt`.

Источник: публичная копия в репозитории SecLists (MIT,
`Passwords/Leaked-Databases/rockyou.txt.tar.gz`). Это реальные утёкшие пароли,
распространяемые для защитных целей и обучения; в приложении они используются
только для проверки «есть ли пароль в списке».
